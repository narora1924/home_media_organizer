Duplicate files

This step groups media files that have the same contents. Keep one file in each group. Ignore leaves the extra copy on disk and drops it from this run. Delete removes it from the input folder after you confirm the list. Files that are not photos or videos are counted and shown below, and they are not copied.

Files that are not media

These files were counted with the totals above. They are not checked for duplicates and are not copied to the output folder.

Already in the output folder

This step compares the media files you kept with the output folder. A file is ignored when the same bytes are already there, or when this organizer has already converted that exact input file. Nothing is copied yet.

Files that will be copied

This step reads the date inside each remaining media file and chooses its year and month folder. If the file has no date inside it, the older of the file's created and modified times is used. JPG and MP4 files that are already compatible will be copied as-is. Other images will be converted to JPG. Other videos will be converted to H.264/AAC MP4. A file that already has that name in the output folder is replaced. A JPG and a HEIC, or an MP4 and a MOV, that share the same name also replace that one file instead of adding a second copy. Nothing is written until you click the button.
